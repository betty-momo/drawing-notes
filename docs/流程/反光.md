# 反光

## 什么是反光

- 反光是主光照到环境、衣服、皮肤、地面后，再反弹进暗部的光
- 它属于**暗部信息**，不是第二个高光，也不是把阴影重新照亮
- 常出现在背光边、接触面附近、物体互相面对的位置
- 判断标准：反光可以比核心暗部亮一点，但不能亮过受光面

## 反光要点

- 先判断反光来源：天空偏冷，皮肤偏暖，草地偏绿，衣物会带自身固有色
- 亮度服从二分：反光要留在暗部组里，不要把投影和闭塞涂没
- 面积宁小勿大：它是让暗部透气的边缘色，不是重新铺一层光
- 边缘跟材质走：皮肤软，头发按发束略硬，金属和玻璃可以更硬更窄
- 颜色比亮度更重要：很多时候只要暗部边缘带一点环境色，体积就会活

## 常用位置

- 下巴与脖子互相反弹的位置
- 鼻翼、脸颊、耳朵等转进暗部的边缘
- 头发背光面和发束交叠处
- 衣褶凹槽边缘、手臂贴近身体的位置
- 金属、饰品、玻璃等高反射材质的背光边

## 图层建议

| 用途 | 图层模式 |
|:--|:--|
| 小范围补环境色 | **普通（Normal）** |
| 轻微提亮暗部颜色 | **叠加（Overlay）** |
| 稍明显的反光边 | **强光（Hard Light）** |
| 金属或玻璃的窄亮边 | **发光（Glow）/ 线性减淡（Linear Dodge）** |

## 检查方法

- 关掉反光层时，画面大明暗仍然成立
- 打开反光层后，暗部更透气，但仍然能看出它在暗面
- 如果反光一多画面变灰、变脏，优先降低亮度和面积，而不是继续加高光
