# 塑造

## 什么是塑造

- 塑造是在大明暗完成后，用边缘、转折、灰面、反光、高光和局部纹理，把形体与材质统一起来
- 它不是把每一块都画细，而是决定哪里该硬、哪里该软、哪里该省略
- 塑造要服务视觉中心：脸、眼睛、胸像上半部可以更完整，远离焦点的地方要主动收

## 塑造顺序

1. 先检查二分和灰面是否通顺，不通顺就先回到大关系
2. 标出主要转折：骨点、褶皱折线、发束鼓点、金属棱线
3. 按材质决定边缘软硬和对比强度
4. 最后用反光、高光和小纹理收焦点，不要一开始就堆细节

## 材质处理

| 材质 | 塑造思路 |
|:--|:--|
| 皮肤 | 软边、低对比、轻微偏红或偏暖，避免硬描结构 |
| 头发 | 按发束成块塑造，叠压处保留硬边，背光边可加入环境色反光 |
| 布料 | 抓受力点和折线，折峰可以硬，宽面过渡要软 |
| 金属 | 高反差、硬边、小面积亮线或白点，暗旁边紧贴亮才像金属 |
| 玻璃 / 水晶 | 用边缘高光、内部暗形和少量背景色做透明感，不要整块涂亮 |

## 金属要点

- 金属不是“更亮的普通物体”，而是反射更强、边缘更硬、明暗跳变更快
- 先画清楚形体方向，再决定它反射到什么颜色
- 高光面积要小，位置要贴合结构面；大面积白会变成塑料
- 金属暗部可以很深，但旁边要有窄亮边或环境反光，才会有锋利感

## 检查方法

- 缩小看，视觉中心是否仍然明确
- 去色看，皮肤、布料、头发、金属的明暗对比是否有区别
- 如果所有边缘都一样硬，画面会碎；如果所有边缘都一样软，体积会塌
