# 光源衰减

## 什么是光源衰减

- 光源衰减是指同一束光落到不同距离、角度、遮挡关系的表面时，强度会发生变化
- 离主光近、面向光、靠近视觉中心的位置更亮、更清楚
- 远离主光、背向光、被遮挡或离焦点远的位置，要降低亮度、饱和度和对比

## 处理要点

- 先定主光位置和视觉焦点，不要全身平均提亮
- 越远离焦点，亮度、饱和度、边缘清晰度都可以递减
- 投影和闭塞负责压空间，反光只在需要透气的位置补一点
- 背景光效优先服务人物轮廓，不要抢主体亮点
- 高光不是哪里都能加，必须服从材质、角度和距离

## 常见用法

- 角色脸和上半身作为最高优先级，手脚、发尾、后景可以压暗或降饱和
- 头发外轮廓可以用背景光拉开剪影，内部不要处处发亮
- 金属受光点可以非常亮，但面积要小；离焦点远的金属只保留关键边
- 背景越远，通常越低对比，避免和人物抢细节

## 检查方法

- 缩略图里第一眼能看向焦点
- 亮点不要散得到处都是，否则衰减不够
- 如果画面很平，优先压远处和背光处，而不是继续加亮主体
