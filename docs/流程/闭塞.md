# 闭塞

## 这一步的定位

- 闭塞是暗部里**基本受不到光**的最深处
- 它不只是“更深的三分”，而是主光、环境光、反光都很难进入的位置
- 明度上要比三分暗得多，是暗部中最重、最压住形体的点
- 通常出现在物体接触面、缝隙、遮挡处、转折压得最紧的地方
- 它的作用是压住空间关系，让物体真的贴在一起、插在一起、盖在一起

## 和三分的区别

- 三分：暗部里还有结构、空气和材质变化，例如阴影里的衣褶折痕
- 闭塞：几乎没有空气，颜色比三分暗很多、更集中，边缘通常更明确
- 三分可以有一点过渡，闭塞不能铺太大，否则会把画面压脏

## 操作方式

- 新建**普通**或**正片叠底**剪贴图层
- 从当前暗部吸色，再往低明度、高饱和或偏冷偏暖方向压
- 用硬一点的笔先确定形状，必要时只在外缘轻微过渡
- 面积宁小勿大，闭塞是“钉子”，不是重新铺一层阴影
- 如果闭塞和三分只差一点点明度，就不够闭塞；它应该明显把接触点压下去

## 常见位置

- 下巴贴近脖子的缝
- 刘海压住脸的位置
- 手指之间、手臂贴住身体的位置
- 衣褶最深的凹槽
- 金属零件、饰品、布料互相遮挡的夹角
