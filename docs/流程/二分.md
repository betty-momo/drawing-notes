# 二分

## 创建二分图层

- 在灰底图层上创建新图层并创建剪贴蒙版，命名为"二分"
- 可以选择偏向环境色的颜色（如 h249、s017、v65 的暗紫色），二分本身颜色不需要太固定

## 初步二分

- 判断好光源的方向，这一步可以找图片参考
- 初次二分只能用**铅笔和橡皮擦**，不能用画笔和喷枪

## 细化二分

### 大块破形

- **背景二分**：在背景图层上同样新建正片叠底图层铺色。由于光源在人物后方，背景的橘色可以比人物部分稍淡一些，通过对比使人物更突出
- **粗略擦出光源**：用橡皮擦大致擦出光源和亮面位置，主要目的是建立背景的明暗对比，无需很仔细
- **加强背景光效**：在背景二分图层上新建一个"发光"图层，选择偏暖光（带黄色）的颜色，喷在亮面以加强塑光效果，作为绘制人物的参照

### 边缘处理

- 一部分二分边缘用水彩笔模糊（不能过多，主要以硬边缘为主）
- 最后压一下明度，将喷枪调制浓度 32、最小大小 42，在明暗交界线处轻轻加深阴影颜色

### 实例分析

- **头发**：材质硬、反光率高，即使转折平缓，模糊程度也**较弱**
- **额头皮肤**：材质软、转折平缓，模糊程度**较强**
- **腰腹皮肤**：转折极为平缓（接近平面），可以**大胆做过渡**
- **胸部金属**：材质坚硬，即使转折平缓，也**保留硬边**
- **手部投影**：属于"硬的阴影"，只需**稍微模糊**

### 节奏与对比

- 过渡的软硬程度也要有节奏变化，不要全部统一
- 腰腹处，只有靠近小腹的平缓处过渡强，其他部分保持较硬边缘
- 手臂的软材质与投影的硬边要拉开对比

> **检查方法**：在检查二分图层时，可以**关闭线稿**，仅依赖色块来感知物体的**体积感**

## 叠加图层处理

1. 二分完成后 Ctrl+左键选择灰底图层，点击二分区域，反选，清除所选图层
2. 复制二分后分别对每个部位创建剪贴蒙版，图层效果设置为**正片叠底**
3. 在二分图层上新建图层，创建剪切蒙版，混合模式选择**叠加**，用喷枪从明暗交界线明显的地方向内喷绘

## 颜色取舍

- 锁定不透明度后选择合适的颜色
- 通常为高饱和往左下角拉一小部分
- **深色**：明度差 20-40
- **浅色**：明度差 10-20
- 色相也要做修改，比如在皮肤会透一点红色（根据光源色和环境色综合决定）

## 加强明暗交界线

- 在**普通视图**下加深明暗交界线周围暗部的颜色
- 可以用**橘色**暖光在明暗交界线处做过渡模糊模拟出照射的感觉
- 其他颜色根据具体环境光来决定
