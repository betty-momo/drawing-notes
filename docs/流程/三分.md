# 三分

## 这一步的定位

- 三分是二分之后的**暗面细分**，可以理解为“暗面里的暗面”
- 它主要处理阴影内部由褶皱、压叠、转折再次产生的小阴影
- 它不负责完整眼睛上色，也不负责最终高光、反光和线稿染色
- 检查标准：关掉三分层后，二分大关系仍然成立；打开后，暗部内部更有结构，但不会跳出暗部组

## 三分该画什么

- 衣褶在阴影里再次形成的折痕阴影
- 发束压叠、刘海遮挡、头发内部的暗面层次
- 双眼皮、眼窝、鼻翼、嘴角、下巴转折等脸部弱结构
- 手指、手臂、衣物和身体互相贴近时产生的小投影
- 已经在二分暗部里的局部转折，不要越过二分边界去重画大光影

## 操作方式

- 新建**正片叠底**或**普通剪贴**图层，颜色从当前暗部吸色后再压暗
- 常用**马克笔**或硬一点的笔刷，先画清楚形状，再按材质决定是否模糊
- 褶皱、金属、发束压叠可以偏硬；皮肤和大软面要保留轻微过渡
- 明度变化不要太大，三分是暗部细节，不是新的二分

## 暗面里的暗面

- 刻画部位：双眼皮、眉弓骨、脸颊转折、鼻翼、下巴、衣褶凹槽、发束交叠等
- 此步骤能产生细微层次变化，同时保持平面感，是二次元绘画的主要思路之一
- 阴影范围不要越过二分边界，只在原本暗部或转折附近补一层更细的暗面

## 伴随补色

- 单独创建普通图层，反复调整位置和形状，不必一笔成形
- 线状的深色部分可以角度交错，避免呆板
- 腮红属于颜色层次，不要画成独立结构阴影
- 在双眼皮等处加几笔高饱和度的红色，增强皮肤透感，与后续眼睛的高饱和上色呼应
- 鼻翼、眼角、嘴角这类肉感位置可以稍微偏红，但要控制面积
- 如果颜色一多就脏，优先降低明度变化，只保留一点色相变化

## 嘴唇

- 按皮肤补色处理即可，不用太明显，避免显得嘴唇厚
- 本质仍然是皮肤颜色变化，不要画成口红

## 局部调整与重色阴影

- 用马克笔补充细节，如下巴轮廓、颜色不够深的阴影等
- 新建**正片叠底**图层，加重色阴影，但不要把闭塞和投影全部混进三分
- 例如在刘海中间用饱和度稍高的颜色，增加透光感，这一层边缘尽量画硬
- 最黑、最贴合、最没有空气的地方仍然归到[闭塞](闭塞.md)

## 不放在三分里的内容

- **眼白、眼影、瞳孔和虹膜**：放到[眼睛上色](../专题/眼睛上色.md)或[皮肤塑造](../专题/皮肤塑造.md)里看
- **最终高光和亮点形状**：放到[高光](高光.md)里处理
- **线稿染色**：属于后期统一，可以放到[塑造](塑造.md)或具体专题页里处理
- **大面积肤色提亮**：优先回到二分或皮肤塑造，不要在三分阶段把明暗关系推翻
